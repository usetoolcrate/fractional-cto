Questions agencies ask

Do you work directly with our clients?

Only if you want me to. By default I'm white-label: I work through you, and the client relationship stays yours.

Will you sign our NDA?

Yes. Confidentiality is part of every written agreement I sign, and I'm happy to work under your agency's own paperwork.

Which platforms do you work in?

WordPress (custom themes and plugins), Shopify, Webflow, concrete5, PHP and JavaScript, plus custom web applications. If a client is on something unusual, ask. I've probably inherited one before.

How does pricing work?

A fixed monthly arrangement sized to how much work you expect to send, or a fixed price for a single defined project. Either way the number is agreed in writing before work starts. I don't bill hourly.

What if you're unavailable?

Your work never depends on me alone. The code sits in your repositories, documented, with written handoff notes, so any competent developer can pick it up.

Can you start on something small first?

Yes. Many partnerships start with one project or a short list of fixes, so you can see how I work before committing to a monthly arrangement.
